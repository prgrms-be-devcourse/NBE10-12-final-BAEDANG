# InvestUP 모바일 디자인 시스템

## 1. 분위기와 정체성

기존 InvestUP 웹의 밝은 푸른 배경·짙은 남색 액션·읽기 쉬운 종목 목록을 Android 화면으로 옮긴다. 정보가 없을 때는 가상의 자산이나 가격을 보여주지 않는다. 초보자가 공개 탐색 후 로그인할 수 있는 흐름이다. 기준은 docs/superpowers/모바일앱_기획서.md와 front/src/app/globals.css다.

## 3. 글자

시스템 한국어 글꼴을 사용한다. Pretendard 파일을 아직 확보하지 않았으므로 설치된 것으로 가장하지 않는다. 본문 16, 보조 14, 소제목 20, 제목 28, 강조 금액 32 논리 픽셀. 시스템 글자 확대를 제한하지 않는다. 금액은 tabular figures로 정렬한다.

## 4. 간격과 화면

간격은 4/8/12/16/20/24/32. 카드 반경 20, 버튼·입력 반경 12. 최소 터치 영역 48. SafeArea 안에서 화면별 ListView가 스크롤을 소유하며 좁은 화면에서 가로 스크롤을 만들지 않는다. 폼은 최대 너비 480, 내용 최대 너비 720. 4탭은 홈/랭킹/가이드/마이이며 선택된 화면만 폴링한다.

## 5. 재사용 컴포넌트와 상태

- AppCard: 동일 패딩/반경의 정보 표면. 내용 길이에 따라 높이 확장.
- AsyncPanel: 초기 로딩, 데이터 없음, 실패+다시 시도, 데이터 있음. 이전 데이터 갱신 실패도 명시.
- Primary action: Material FilledButton. 제출 중에는 중복 조작을 막고 진행 상태 텍스트 제공.
- Form field: TextFormField, 영구 label, 필드별 validation, 비밀번호 보기/숨기기.
- Market badge: 장 열림/마감/확인 불가를 텍스트로 표현.
- Ranking row: 순위/이름/심볼/현재가/등락률, 가격 누락은 대시. 미구현 상세 기능을 누를 수 있는 것처럼 꾸미지 않음.

## 6. 상호작용

기본 Material focus/pressed/disabled 상태 사용. 장식적 자동 애니메이션은 추가하지 않는다. 시스템 동작 감소 설정을 존중한다. 로그인 후 이전 내부 화면으로 복귀하되 동작을 자동 제출하지 않는다. 실패는 지속 안내와 명시적 재시도 제공.

## 7. 표면

웹과 같은 얇은 경계선, 그림자 없는 카드. 색 대비와 여백으로 계층을 표현한다. 라이트/다크는 같은 정보 계층을 유지한다.

## 8. 접근성 제약과 검증 범위

한국어 라벨, 화면 읽기용 버튼 설명, 48 이상 터치 영역, 글자 확대/키보드 표시 시 폼 스크롤, 오류 전달, 색상 외의 등락 표시를 필수로 한다. 실측하지 않은 대비·TalkBack 결과는 통과로 기록하지 않는다. 첫 단계는 인증/공개 조회/계좌 요약이며 차트·주문·재설정은 후속 구현 대상이다. 검증 증거와 실제 제한은 README에 기록한다.
