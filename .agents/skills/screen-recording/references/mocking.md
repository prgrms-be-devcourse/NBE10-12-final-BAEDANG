# 응답 목 패턴과 화면별 사실

샷에서 장중 화면·체결·계좌 상태를 만들어 보여줄 때 참고한다. 앱 코드가 바뀌면 여기 적힌 사실도 틀릴 수 있으니, 녹화가 실패하면 `front/src`에서 다시 확인한다(작성 기준 2026-09-15).

## 목차

1. Playwright 라우트 기본 규칙
2. 로그인·장 상태
3. 실시간으로 바뀌는 배경
4. 샷끼리 일관된 계좌 시나리오
5. 화면별 사실(선택자·문구·입력 순서)
6. 투자 성향 리포트 판정 규칙
7. 국내 호가 단위

## 1. Playwright 라우트 기본 규칙

- **나중에 등록한 라우트가 먼저 처리된다.** 그래서 "목으로 처리하지 않은 쓰기 요청은 차단" 같은 안전망을 가장 먼저 등록하고, 개별 목은 그 뒤에 등록한다.

  ```js
  await page.route(api(/^\/api\/(orders|accounts|stocks\/likes|auth|users)/), (route) =>
    route.request().method() === 'GET' ? route.fallback() : route.abort());
  ```

- API는 배포 프론트와 다른 호스트로 갈 수 있으니 URL 전체가 아니라 **pathname 정규식**으로 매칭한다: `const api = (re) => (url) => re.test(new URL(url).pathname);`
- 실제 응답을 조금만 바꿀 때는 `const res = await route.fetch(); const body = await res.json();` 후 필요한 필드만 덮어 `route.fulfill({ json })`. 목록형 응답처럼 건드리지 않을 것은 `route.fulfill({ response: res })`로 그대로 넘긴다.
- `/api/stocks/[^/]+` 같은 패턴은 `/api/stocks/likes`, `/api/stocks/search`도 잡는다. 본문 모양으로 걸러내거나 더 구체적인 라우트를 나중에 등록한다.

## 2. 로그인·장 상태

| 목적 | 경로 | 응답 |
|---|---|---|
| 로그인 상태 복원 | `POST /api/auth/refresh` | `{ accessToken: '<아무 문자열>' }` |
| 사용자 정보 | `GET /api/users/me` | `{ userId, email, nickname }` (상단에 "닉네임님") |
| 장 열림 | `GET /api/market/status` | 실제 응답의 `markets[].open`을 `true`로 |
| 종목 거래 가능 | `GET /api/stocks/{symbol}` | `tradable: true, tradableReason: null`, `price.quoteAt`을 장중 시각으로, `realtime: true` |
| 환율 고정 | `GET /api/exchange-rates/latest` | `rate`만 시나리오 값으로 |

- 로그인이 목이면 인증이 필요한 GET(계좌·보유·주문·원장·리포트·관심 종목·주문 미리보기)도 전부 목이어야 한다. 가짜 토큰으로 실서버를 부르면 401 → refresh → 401이 반복된다.
- `quoteAt`을 실제 시각으로 두면 "오후 4:13 기준"처럼 장 마감 뒤라는 게 드러난다. 오늘 날짜의 장중 시각(예 10:30)부터 경과 시간만큼 흐르게 한다.

## 3. 실시간으로 바뀌는 배경

- 종목 상세 현재가: **5초** 폴링(`app/stocks/[symbol]/page.tsx`, 장 열림일 때만)
- 호가창: **3초** 폴링(`OrderBookPanel`, 장 열림일 때만)
- 마이페이지 계좌 요약·보유: 5초 폴링
- 호출 횟수로 값을 바꾸면 결정적이라 다시 찍어도 같은 모습이 나온다.
- **체결가를 샷끼리 맞춰야 하면** 호가창 기준가는 고정하고 잔량만 출렁이게, 현재가는 기준가와 매수 1호가 사이만 오가게 한다. 그러면 매도 1호가가 늘 같아 언제 주문해도 같은 가격에 체결된다. 폴링 변화를 기다리며 주문을 미루지 않는다(샷이 길어진다).

## 4. 샷끼리 일관된 계좌 시나리오

- 보유 종목 표 하나(종목·수량·평균단가·현재가·매수 시각·매수 환율)에서 **요약·보유·주문 내역·체결 내역(잔액 흐름)·성향 리포트**를 모두 계산한다. 따로 하드코딩하면 반드시 어긋난다.
- 계산 규칙: 원가 = 평균단가 × 수량 × 매수 환율(원 반올림), 수수료 = 원가 × 0.01%(반올림), 예수금 = 초기자금 − Σ(원가 + 수수료), 평가금액 = 현재가 × 수량 × 현재 환율, 평가손익 = 평가금액 − 원가.
- 원장은 오래된 순으로 잔액을 누적한 뒤 최신순으로 뒤집어 내려준다. 첫 줄은 `INITIAL_DEPOSIT`.
- 주문 전/후 두 상태를 같은 함수로 만들고 `check`에서 단언한다: 원장 마지막 잔액 = 예수금, 전후 예수금 차이 = 주문 순금액, 성향 코드 기대값.
- 5a(주문)와 5b(결과)처럼 다른 프로세스에서 찍는 샷은 체결 시각·체결가를 상수로 공유한다.

## 5. 화면별 사실

**종목 상세 주문 패널** (`components/StockDetailClient.tsx`)
- 시장가: `시장가` → `매수` → 수량 `[data-tour="quantity"] input` → 버튼 `매수하기` → 팝업 제목 `거래가 체결됐어요`
- 지정가: `지정가` → `매수` → **지정가 칸(placeholder `예: 72000`)을 먼저 비우고 입력** → 수량 입력 → 미리보기 `호가 기준 즉시 체결 예상` → 버튼 `매수 주문 접수` → 팝업 제목 `주문이 접수됐어요`
  - 지정가 칸은 현재가로 미리 채워진다. 비우지 않으면 뒤에 이어 붙는다.
  - 수량은 주문가능금액으로 살 수 있는 최대치로 즉시 깎인다. 가격이 비어 있으면 최대 0주라 수량이 0이 된다.
  - 미리보기(`GET /api/orders/quote/limit`)는 입력이 멈추고 500ms 뒤 호출된다.
- 종목 상세 첫 진입 투어 팝업: `localStorage.stockDetailTourSeen_v1 = '1'`로 끈다.
- 주문 응답 모양: 시장가 `MarketOrderResponse`, 지정가 `OrderDetailResponse` (`lib/api.ts`)

**마이페이지** (`app/my/page.tsx`)
- 제목 `내 계좌`, 탭 `보유 종목 · 주문 내역 · 체결 내역 · 관심 종목`
- 탭을 누르면 목록을 다시 불러온다. 그려졌는지 기다릴 글자: 주문 내역 `체결완료`, 체결 내역 `초기지급`, 관심 종목은 종목명(부분 일치 — 행 안에 다른 글자와 섞여 있다)
- 시장가 주문은 주문 내역 가격 칸이 `-`로 나온다(앱 동작).
- 페이지 맨 아래에 계정 설정·포트폴리오 초기화·회원 탈퇴(빨간 영역)가 있다. 리포트까지 내릴 때 끝 장면에 걸리지 않게 스크롤을 멈춘다.

**랭킹** (`app/rankings/page.tsx`): 탭 `국내 주식`/`해외 주식`, 종목명 텍스트는 숨은 복제본이 먼저 잡힌다.
**인트로** (`components/InvestupIntro.tsx`): 섹션 `#hero #practices #compare #zoom`, 마지막 CTA 링크 `시작하기`는 페이지 끝까지 스크롤해야 opacity 1이 된다.
**용어 위키** (`/guide` → `금융 용어 위키`): 검색창 placeholder `용어·별칭·초성(ㅅㄱ)으로 검색`, 결과는 버튼, 풀이는 `role=dialog`.

## 6. 투자 성향 리포트 판정 규칙

백엔드 `report/support/InvestmentTypeClassifier.java` 기준. `GET /api/reports/me`를 만들 때 보유 종목과 맞춘다.

- 공개 조건: 계좌 개설 후 4주(`locked: false`, `unlockAt` = 개설 + 28일). 보유 2종목 이상이어야 `classified: true`.
- 비중은 4주 창의 **원가 비중 일평균**이다. 4주 넘게 들고 있던 종목은 그 원가 비중이 곧 평균이고, 오늘 산 종목은 거의 반영되지 않는다.
- 4축 컷오프(`>=`): 최대 1종목 비중 0.50 → C(집중)/D(분산), 국내 0.50 → K/G, 개별주+우선주 0.50 → S/E(ETF·ETN), 레버리지(배율≥2)·인버스 0.20 → A/B.
- 국내 상장 해외지수 ETF(예: TIGER 미국S&P500)는 **국내(K)**로 센다.
- `longHeldStocks`: 4주 이상 보유 종목, 오래된 순, `returnRate`는 종목 통화 기준 `(현재가 − 평균단가) / 평균단가`.
- 유형 별명·이미지: `front/src/lib/personality-types.ts` (예: DKSB "국장 균형러").

## 7. 국내 호가 단위

2천원 미만 1, 5천원 미만 5, 2만원 미만 10, 5만원 미만 50, 20만원 미만 100, 50만원 미만 500, 그 이상 1,000원. 가상 호가창은 기준가 위(매도)·아래(매수)로 이 단위만큼 10단계씩 만든다.
